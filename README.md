# SpotifyCares AI Support Agent

AI support agent for SpotifyCares (Hiver SDE Intern take-home). Built for the Kaggle *Customer Support on Twitter* dataset.

## What it does

Per incoming customer message:
1. **Classifies intent** into one of 8 categories (see taxonomy below)
2. **Drafts a reply** grounded in SpotifyCares' historical responses via TF-IDF retrieval
3. **Decides auto-handle vs escalate** using a hybrid rule+LLM policy

## Reproduce headline results in <15 minutes

```bash
# 1. Clone and install (Python 3.10+)
git clone https://github.com/adityaxxz/hiver-ai-assignment.git
cd hiver-ai-assignment
uv venv .venv && .venv\Scripts\activate  # Windows
# or: source .venv/bin/activate  (Linux/macOS)
uv pip install -r requirements.txt

# 2. Download the Kaggle dataset
# Go to: https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter
# Download twcs.csv and place it at: data/raw/twcs.csv

# 3. Create a .env file and set your Groq API key (free at console.groq.com)
# Create a file named .env in the root directory and add:
# GROQ_API_KEY=your-key-here

# 4. Prepare data (~2 min)
python run_pipeline.py prep

# 5. Run agent on a single message
python run_pipeline.py run "my Spotify keeps crashing on my iPhone"

# 6. Run on 10 random sample messages (~3 min with rate limits)
python run_pipeline.py sample 10

# 7. Run full eval harness against golden set (~10 min)
python run_pipeline.py eval
```

Results will be saved to `eval/results_summary.md` and `eval/results.json`.

## Intent Taxonomy

Defined by reading ~150 real SpotifyCares customer messages and clustering informally.

| Intent | Description | Example |
|--------|-------------|---------|
| `account_access` | Login, password, locked account | *"I can't log into my Spotify account, keeps saying wrong password"* |
| `billing_subscription` | Charges, refunds, payment issues | *"I was charged twice for premium this month, I need a refund"* |
| `playback_technical` | App crashes, buffering, songs not playing | *"Spotify keeps crashing on my iPhone every time I open a playlist"* |
| `cancellation` | Wants to cancel or knows how to cancel | *"Please cancel my Spotify Premium subscription immediately"* |
| `feature_question` | How do I do X, where is feature Y | *"How do I download songs for offline listening?"* |
| `complaint_general` | Venting, bad experience, no specific ask | *"Spotify's new UI update is awful and unusable"* |
| `praise` | Positive feedback, no action needed | *"Love the new Discover Weekly feature, great job!"* |
| `other` | Catch-all — kept <15% of golden set | *"What are SpotifyCares hours?"* |

**Escalation policy:** `billing_subscription` and `account_access` always escalate to a human (money and account security require human oversight — mirrors Hiver's own product philosophy). Low classifier confidence (<0.70) or strong negative sentiment also trigger escalation.

## Architecture

```
data/raw/twcs.csv
  -> src/data_prep.py      cleaned_pairs.parquet (5k SpotifyCares pairs)
  -> src/retrieval.py      TF-IDF CaseRetriever (cosine similarity over customer_message)
  -> src/agent.py          classify_intent() / draft_reply() / decide_escalation()
  -> src/pipeline.py       run_agent(message) -> unified result dict
  -> src/baselines.py      TrivialBaseline + SimpleBaseline
  -> src/eval_harness.py   golden set evaluation, LLM judge, judge-vs-human agreement
  -> run_pipeline.py       single CLI entrypoint (prep / run / sample / eval)
```

**LLM:** Groq free tier (`openai/gpt-oss-20b` for classify/escalate, `openai/gpt-oss-120b` for draft/judge). Direct API calls, no agent framework.
